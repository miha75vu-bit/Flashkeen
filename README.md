# Flashkeen — простое управление дисками, бэкапами и Entware на Keenetic/Netcraze без ПК

Flashkeen — интерактивный помощник для роутеров Keenetic/Netcraze, включая устройства со сторонними портами прошивки. Он объединяет в одном меню основные операции с дисками и Entware: разметку, форматирование, создание, удаление и изменение размера разделов, установку и перенос Entware, работу с бэкапами (KeenSnap/KeenKit), а также обновление пакетов одной командой.

Если роутер новый: Flashkeen поможет подготовить накопитель, установить Entware с нуля (на USB или во внутреннюю память) либо восстановить бэкап с предыдущего роутера. Все действия выбираете вы — без вашего согласия программа ничего не делает.

Если вы уже пользуетесь роутером: Flashkeen позволит создавать и восстанавливать бэкапы, готовить резервные разделы с Entware для быстрого переключения на рабочую конфигурацию, проверять диски и выполнять другие сервисные операции.

Программа подходит для роутеров с USB и без него, работает с официальными и неофициальными прошивками Keenetic/Netcraze и предлагает подходящие варианты ПО для конкретного устройства.

Автор настоятельно рекомендует просто ознакомиться с пунктами меню Flashkeen: их названия помогут разобраться в возможностях программы и понять, для чего предназначена каждая опция :)

## Основная идея
---
Основная задача Flashkeen — максимально упростить установку и перенос Entware на Keenetic/Netcraze: меньше ручного ввода, меньше лишних действий за пределами меню и больше настроек, которые по умолчанию работают правильно. Там, где есть риск потери данных, программа предупреждает пользователя.

Форматировать флешку для Entware в Windows с помощью сторонних программ — ненадежное решение. Это может привести к проблемам с файловой системой и нестабильной работе даже спустя длительное время. Flashkeen выполняет разметку и форматирование непосредственно на роутере с помощью Linux-утилит.

Не менее важная задача — сохранить возможность быстро восстановить рабочую конфигурацию Entware. Бэкапы и резервные разделы позволяют вернуться к рабочему состоянию после неудачных изменений, не боясь экспериментировать с дополнительными возможностями роутера.

## Возможности

### Диски и разделы
- Быстрая подготовка раздела под Entware (ext4, в т.ч. варианты для слабых флешек).
- Быстрое форматирование под Entware “в один клик” для выбранного раздела.
- Полное управление диском: разметка “с нуля”, форматирование, удаление/создание разделов, изменение размера, проверка ФС.
- Безопасные подсказки и блокировки опасных действий.

### Бэкапы и перенос Entware
- Создание бэкапа Entware и перенос на другой раздел/диск одной кнопкой с помощью соответствующей вашему роутеру программы из меню флешкина.
- Управление бэкапами: распаковка/запаковка/переименование/удаление.


### Установка Entware “с нуля”
В меню бэкапов есть пункт **«Автоматическая установка Entware на USB или внутреннюю память»**.

Flashkeen сам определяет архитектуру роутера, запускает установку Entware и переключение OPKG. Для внутренней памяти есть отдельное подменю установки и очистки системного раздела.

### Обновление Entware
- Пункт меню: `opkg update && opkg upgrade`
- Команда `update`: запуск обновления без открытия интерфейса Flashkeen.

## Установка и запуск Flashkeen - просто нажмите "f"

### Обычная установка

Подключиться по SSH к Entware и выполнить:

```sh
opkg update || true; opkg install curl || true; curl -fsSL https://raw.githubusercontent.com/miha75vu-bit/Flashkeen/main/install.sh | sh
```

### Оффлайн-установка

Если на роутере недоступен GitHub или нет сети, используйте оффлайн-версию Flashkeen.

[Команда для установки, если недоступен GitHub на роутере или нет сети](https://github.com/miha75vu-bit/Flashkeen/blob/main/install%20ipk%20offline)

Положить Flashkeen в корень диска, скопировать весь текст из инструкции и вставить его в командную строку.

### Первые шаги, с чего начать?

Нельзя переразметить диск, с которого запущены Flashkeen и Entware. Поэтому сначала нужно выяснить откуда мы будет запускать Flashkeen, из готовой или временной Entware — во внутренней памяти роутера, имеющемся разделе или на другой USB-флешке.

**Рекомендуемая структура флешки:**

- **Основной Entware** — 2–3 ГБ. Рабочая система.
- **Резервный Entware** — 2–3 ГБ. Копия настроенной системы для быстрого восстановления.
- **Раздел данных** — от 1 ГБ до всего оставшегося места. Для файлов и бэкапов. Создайте на нём папку `Backup`.
- **Базовый Entware** — 1–3 ГБ, необязательно. Чистая Entware с Flashkeen и базовыми инструментами.

Разделы создаёт мастер Flashkeen. Вручную размечать диск заранее не нужно.

5. Если базовый раздел не нужен, переходите к настройке программ. Для чистого базового раздела потребуется отдельный бэкап чистой Entware.

3. Главное меню → **2) Резервное копирование…** → **2) Создать бекап используемой Entware…**. Перенесите бэкап на новый раздел и согласитесь переключиться на него.
4. Убедитесь, что новая Entware работает. Затем удалите старый раздел и создайте на освободившемся месте остальные необходимые разделы.

### 2) Что именно бэкапит и переносит Flashkeen?
Фактически — **всю Entware**: пакеты, настройки и установленный софт. Можно держать несколько разделов и переключаться между ними. Для настроек самого роутера (и того что вы туда устанавливали, например конфигурации серверов - воспользуйтесь опцией бекапа в нем.

---

### 3) Рекомендуемая конфигурация разбивки флешки на разделы?
Flashkeen подсказывает разумные варианты по умолчанию (размеры/метки/тип ФС) и предупреждает об опасных действиях. Если диск новый или хотите “с нуля” — используйте разметку “с полным удалением данных”, он сам разобьет диск в зависимости от его размера на оптимальную конфигурацию, включая данные.

Также в Flashkeen есть разные “режимы удобства”, чтобы не копаться в меню:
- **Быстрое форматирование под Entware одной кнопкой** (для выбранного раздела).
- Полный режим управления разделами (разметка, создание/удаление, проверка ФС и т.д.), если нужно настроить диск “под себя”.

<details>
<summary><b>Про количество и назначение разделов Entware и метки</b></summary>


**Почему несколько разделов Entware — это удобно**  
Практика показала, что удобнее всего иметь несколько независимых разделов под Entware на одном диске. Это даёт безопасные эксперименты, быстрый откат и “запасной план”, если что‑то сломалось после обновлений или настроек.

**Типовая логика (по умолчанию) — 3 раздела:**

- **Основной раздел Entware**  
  Ваш рабочий раздел, где всё “как обычно”: пакеты, настройки, сервисы.

- **Второй рабочий раздел Entware (резерв/эксперименты)**  
  Нужен, чтобы:
  - спокойно экспериментировать (пакеты, конфиги, обновления);
  - иметь быстрый откат: просто переключили OPKG на другой раздел и вернулись к рабочему состоянию;
  - держать альтернативную конфигурацию (например “минималка” и “боевой”).

- **Базовый раздел (“Base”)**  
  Это “чистая база” — минимальная Entware или заранее подготовленный минимальный набор, который удобно использовать как:
  - аварийный старт, если оба рабочих раздела требуют ремонта;
  - основу для быстрого развёртывания (сделали бэкап → развернули/перенесли);
  - контрольную точку “точно работает”.

**Про метки (`Entware_USB`, `Entware_USB_2`, `Entware_Base` и т.п.)**  
Flashkeen старается давать понятные метки, чтобы не путаться, какой раздел для чего:

- `Entware_*` — раздел под Entware  
- `*_2` — второй рабочий Entware‑раздел (резерв/эксперименты)  
- `*_Base` / `Entware_Base` — базовый (минимальный/аварийный) раздел

</details>

### 4) Какую файловую систему выбрать?
Flashkeen умеет форматировать разделы в разные ФС (включая `ext4`, `ntfs`, `swap`).  
Для Entware обычно используется **`ext4`**, а для слабых флешек есть вариант **ext4 без журналирования** — он снижает лишние записи и экономит ресурс накопителя.

---

### 5) Нужен ли для работы интернет, много ли места занимает?
Сам Flashkeen совсем небольшой, а необходимые утилиты для работы с дисками обычно занимают немного, буквально мегабайты. Интернет нужен для установки и в моменты скачивания пакетов/инсталляторов в соответствующих пунктах. Есть версия оффлайн без интернета, устанавливается просто по инструкции выше.

---

### 0) Flashkeen сам обновляется? Что такое `test` и выбор версий?
Flashkeen умеет проверять обновления при запуске (не чаще раза в сутки) либо команде в терминале "update". Сам процесс автообновления в фоне не запускает.
Также в Flashkeen есть:
- **Команда `test`** в главном меню — включает меню переключения между версиями
- **Выбор версии Flashkeen** — в меню можно выбрать и установить другую версию Flashkeen с GitHub (например откатиться или перейти на тестовую).
